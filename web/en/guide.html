How to use SMS Hub

SMS Hub is a free online SMS receiver with no signup. Pick a country and a number, then wait for and read the public verification codes right here on the site.

🔒
Important: Anyone can read SMS sent to a public number. Never use one for banking, payments, email, identity verification or any other sensitive account.

Four steps to receive a code

1

Pick a number

Choose a country on the home page, or tap “Pick a number for me” to get a currently active one.

2

Copy the number

On the number’s page tap “Copy number”. Copying also starts this page waiting for new SMS automatically.

3

Paste into the target site

Paste the number into the phone field of the site or app you are signing up for, then request the code.

4

Read and copy the code

New SMS is pinned to the top and highlighted, the code is detected — just tap “Copy code”.

What the statuses mean

Every number shows a status to help you decide which one to try first:

  • ● Available There have been recent successful deliveries — try these first.
  • ● Low usage The number is relatively quiet; it may take longer.
  • ● Unverified Not enough activity evidence yet — delivery is not guaranteed.

What to do if you get no SMS

  • Wait 1–2 minutes first. Some services are simply slow to send the code.
  • Tap “Refresh now”. This page auto-checks every 15 seconds; you can also refresh immediately.
  • Try another number. The number page offers “Try another number” from the same country — no need to go back and re-pick a country.

FAQ

Do I need to sign up or pay?

No. SMS Hub is completely free and requires no account. Pick a number and use it right away.

Why can’t I read SMS for some numbers?

Only a limited set of numbers can be read on this site. Others can only be viewed on the original source, and we provide a link. The home page and default list only recommend numbers readable here.

Why is a number shared by many people?

These numbers are public temporary numbers — anyone may use them. That is exactly why you should never use one for a sensitive account.

Why do I see “too many requests”?

To avoid stressing the upstream site we enforce a 15-second minimum interval per number and a per-minute cap per visitor. It retries automatically after a short wait.

How accurate is code detection?

The system extracts likely codes from the message body and highlights them, but the result is only a hint — always verify against the original message.

Can I recover my number after closing the page?

The number page remembers the session you are waiting on. Reopening it offers to continue waiting — no progress is lost.

Frequently asked questions

The questions users ask most about the free SMS Hub platform.

Is SMS Hub free? Do I need to sign up?

Completely free — no signup. Open the site, pick a country and a number, and use it right away.

Why can other people see these numbers’ messages?

These numbers are public temporary numbers on the internet and their messages are public too. Therefore anyone can see the SMS received by the same number. That is exactly why you must not use them for any sensitive account.

Can I use it to sign up for Google / Telegram / WhatsApp?

We do not promise that any specific service will receive the code. Some platforms block known public temporary numbers. Status labels are only a hint based on past activity — they are not a promise that a number works for a given service.

What if I do not receive the SMS?

  • Wait 1–2 minutes first — some services are slow to send the code.
  • Tap “Refresh now” on the number page to check immediately (the page also auto-checks every 15 seconds).
  • Still nothing? Tap “Try another number” and retry with a new one.

Why can’t I read SMS for some numbers here?

Each upstream site exposes message bodies to a different degree, so the set readable here is limited. The rest can only be viewed on the original source — we provide links and keep them in a spare pool, excluded from home recommendations and the default list.

What does “too many requests” mean?

To protect upstream sites, each number may be queried only once per 15 seconds and each visitor has a per-minute cap. It retries automatically after the indicated wait — no manual action needed.

How accurate is code detection?

The system extracts likely codes and highlights them, but the result is only a hint — verify against the original message. If detection fails, use “Copy message” to get the full text.

Do I lose progress after closing the page?

No. The number page remembers your waiting session locally, and reopening the same number offers to continue waiting. Switching numbers or clearing browser data resets the session.

Does this site store message content?

Messages shown here come from third-party public pages and are rendered live only — this site does not centrally store message bodies or codes. The number index and status data are refreshed periodically.
